# R1 versus R1 plus P14

Both arms use one immutable source with P8g/P8c/P9/P10/P8d/P13 enabled. The
candidate adds the existing search-only P14 feature. P15/P11/P12/E/F remain off.
This is an incremental combination experiment, not adoption or a KEEP-R2 registry.

Fresh 6,184-case oracle/turn/search evaluation uses exact raw output without a new
instruction, legality or denominator exception. Existing P8c/P9 precedence and
nonleaf probes remain unchanged. Both arms then run full release regressions;
actual compiled feature closures require P13 in core and search, and P14 only in
candidate search. Timing has no observers and uses generic x86-64, one thread,
the frozen coaching/sand harness, ten alternating AB/BA pairs and separate RSS2.

The bounded P14 proof has six public configurations: dense/compact observer
OFF/ON plus compact plain OFF/ON. Removing the old two dense plain duplicates
retains both storage representations, both runtimes and an observer-free pair.
The original four observer library proofs still execute every required P14
shape/NaN/error/choice-order/owned-buffer test and isolated allocator subprocess.
Their 1,378 complete matrix records and all six 51-case public streams must match
byte for byte. Frozen P14 parsers are imported without modification.

The P13 and P14 unit modules each own a global allocator. A source test-only guard
isolates them. One additional compact candidate debug libtest with both observers
uses the existing P13 tests, allocation/collision/error proof and five private records;
it requires P14 runtime ON and no P14 allocator test module. No allocator test
body changes. Actual coaching/sand observation uses two release examples, where
cfg(test) is absent, with both observers enabled. P14 accounting/pass activation
and positive P13 borrowed-key activation are required; P13 job/query/collision
counters and complete semantic/integer work output must match across arms.

Cache fingerprints bind the new wrapper and the imported P13/P14 gates. Cached
correctness results never replace fresh evaluation or regressions. Local source
log parsing proves parser compatibility only, not actual workload speed.
