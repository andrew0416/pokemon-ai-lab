## 중간 상태와 비AVX2

엔진 56구성의 최종 지문은 비계측·계측·shadow 빌드에서 일치. 중간 검사 합계: {'compiled_snapshots': 434, 'sequence_snapshots': 124, 'contractions': 774, 'gap_checks': 372}. 추가 64 seed leaf replacement 코퍼스는 정보 ID 재배치, 효용 scale 변경, 0·극소 chance와 이전 비말단 불변 계약을 검사한다. 일반 가변 트리 지원을 약속하지 않는다.

qemu-x86_64 version 8.2.2 (Debian 1:8.2.2+ds-0ubuntu1.18), Nehalem CPU 모델에서 CPUID AVX=false, AVX2=false, SSE2=true를 확인한 뒤 엔진 2조건×3구성과 기존 스칼라 finite-tree 경로를 실제 실행했다. native 결과와 전체 JSON이 일치했다. 실제 구형 하드웨어 시험이나 해당 하드웨어의 속도 측정은 아니다.

## 다음 구현

이력 키를 매번 처음부터 Debug 포맷하는 비용이 8조건에서 11~14%다. S25에서 부모 키의 prefix를 복사하고 새 행동·관측 두 항목만 기존 Memory Debug 형식으로 붙이는 후보를 구현한다. 관측이나 평가 함수를 캐시하지 않고 공용 이력의 정렬·정보 구분도 보존한다. 속도와 메모리는 별도 비계측/계측 실행으로 판단한다.

모든 옵션은 기본 OFF이며 생산 엔진에는 적용하지 않았다. 승률을 평가하지 않았다.
