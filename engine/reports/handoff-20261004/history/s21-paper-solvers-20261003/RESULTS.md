CFR 규칙 교체, 정책 재인증 및 warm start, 행렬/다중 턴 행동열 압축을 각각 독립 옵션으로 구현했다. 실험 전용이며 기본 OFF다. 원래 scalar/serial 경로, 범용 x86-64 빌드, 생산 코드와 공유 Git 체크아웃을 보존했다.

독립 LP 인증은 기존 313건과 새 787건을 합쳐 1100건 통과했다. 새 표본은 고정 게임 29개·성장 게임 12개에 여러 규칙/예산을 적용한 것이며, 787개의 독립 게임은 아니다. 새 검사의 12건은 반복 cap에서 미수렴으로 정직하게 표시됐다. 인증 수치 자체는 전수 best response/LP와 일치했다.

18개 실측 조건에서 150개 pair 중 150개가 같은 gap 조건을 충족했다. 실측에서는 제외된 pair가 없었다. (위 정확성 검사 12건의 cap 결과와는 다른 표본이다.) 7개 ABBA/BAAB block의 중앙 비율과 paired bootstrap 95% 구간이다. 단축률은 block별 비율의 중앙값이며 표의 두 ms 중앙값을 나눈 값과 다를 수 있다. 기계 간 불확실성이나 승률을 뜻하지 않는다.

## 이번 판단

일관된 후속 채택 후보는 **LCFR + 일반 행동열 압축**이다. 같은 기존 규칙·검사 간격·cadence를 유지한 6개 전체 성장 사례에서 **1.99~3.98% 단축**, 이 러너의 95% 구간도 모두 후보가 빠른 쪽이었다. 기본 ON 전에는 다른 러너 세션에서 재현을 확인해야 한다.

규칙 교체는 조건부다. pivot의 DCFR은 풀이 70.80%, 전체 3.22%를 줄였지만 stats의 전체 시간은 악화되었다. 정책 재인증은 stats에서 풀이를 생략했으나 pivot·좁은 3턴에서는 비용이 늘었다. warm8은 같은 동시 CFR 기준 stats에서 20.77~28.26% 단축했지만 좁은 3턴은 47.66% 느려졌다. 개선된 warm도 이번 사례에서는 원래 S19 LCFR의 전체 시간보다 느리므로 이를 새 기본으로 삼지 않는다.

엄격한 gap 0.01의 sand 고정 트리에서는 SAP+행렬이 581.460→1.401 ms, 99.76%를 줄였다. 이는 **이미 트리가 완성된 뒤의 풀이만** 비교한 것으로, 전체 엔진 시간의 99.76% 단축이 아니다. 어떤 단일 설정도 이번에 생산에 채택하지 않았다.

정책 재사용은 새 게임에서 원본 gap을 재검사해 통과할 때만 풀이를 생략한다. warm 초기화는 simultaneous CFR에만 허용한다. 행렬 특례는 제한된 단일 결정 게임, 일반 sequence kernel은 완전 기억을 보존한 다중 턴 게임용이다. 두 경로 모두 최종 인증은 압축하지 않은 원본 Tree에서 수행한다.

로컬은 정확성 검사만 실행했다. 생산 미채택, 기본 OFF, AVX2 불필요. 단일 러너 결과이므로 작은 차이는 재현 확인이 필요하며 이번 수치로 승률 향상을 주장하지 않는다.
