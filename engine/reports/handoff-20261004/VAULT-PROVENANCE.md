# 로컬 볼트의 엄밀한 조회

볼트 경로는 로컬 `D:/pokemon-ai-lab/knowledge-vault`이며 `.gitignore`로 공유 브랜치에서 제외한다. 이 폴더에는 볼트 파일을 복사하지 않았다. 대신 소스·실험 근거와 독립 재계산 도구를 프로젝트 보고서로 제공한다.

진입 노트는 `MAP-HANDOFF-20261004`다. 주장 ID H01–H19를 지표 정의·사실·범위·설계 가설·보존 계약으로 분리하고, 각 노트에 질문, 단일 주장, 근거 파일/해시/행, 반증 조건, 연결 이유, 적용 범위, 후속 과제를 둔다. 원래 S26L 집계 노트는 삭제하지 않고 새 원자 노트의 상위 문맥으로 연결한다.

정적 분석 당시 코드와 보드가 나중에 바뀌어 1069개 source reference가 오래된 상태였다. 그 중 **1063개는 기존 SHA256과 바이트가 같은 원본**을 Git 또는 보존된 파일의 검증된 prefix에서 복구했다. 기존 주장/해시/행을 바꾸지 않고 immutable archive를 가리키도록 한다. 이는 과거 스냅샷의 출처 복구이며 현재 WIP를 다시 분석했다는 뜻은 아니다.

남은 6개는 P8c README의 과거 버전이다. 정확한 원본은 찾지 못했고 최신 README 해시로 덮어써 통과시키지 않는다. `historical-source-blobs/RECOVERY.json`에 미복구 SHA와 범위를 남긴다. 해당 옛 노트의 실행 상태는 오래됐을 수 있다. 최신 S27 결론은 이 미복구 문서에 의존하지 않는다.

검증은 전체 vault의 오류/오래된 참조 수와 최신 원자 subgraph의 엄격한 통과를 분리해서 보고한다. 전역 검사에 미해결 근거가 남아 있으면 전체 통과라고 표시하지 않는다.
